# Teacher Planner Platform — Public Demo

A browser-based teacher planning and classroom organisation prototype prepared as a **public portfolio demo**.

## Privacy and demo status

This repository contains **fictional demonstration data only**. The public build has been sanitized to remove real school branding, logos, internal calendar dates, institutional report definitions, school-specific grading rules and production/student data.

Do **not** use this static demo to store real student or confidential school information. The current public build stores data locally in the browser and is a product prototype rather than a production school information system.

## Demo features

- Classes and fictional student records
- Lessons and weekly teaching calendar
- Attendance tracking
- Assessments, grades and progress views
- Homework tracking
- Yearly and weekly planning
- General academic calendar with import tools
- Generic report-card builder and EAL support
- Resources and attachments
- Tasks, notes, meetings and contacts
- Appearance themes and multilingual interface
- Local backup/sync workflows
- Optional local AI gateway hooks (not configured in the public demo)

## Publish with GitHub Pages

1. Create a public repository such as `teacher-planner-demo`.
2. Upload `index.html`, `.nojekyll`, `README.md`, and `LICENSE_NOT_SELECTED.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then select **main** and **/(root)**.

The GitHub Pages URL remains unchanged when `index.html` is updated later.

## Security

The public demo intentionally has no production authentication, central database or role-based security. A production implementation should add authenticated users, protected storage, database-level authorization and appropriate data-protection controls before handling real learner information.
